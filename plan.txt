
# Cultura Database Reorganization Plan

## Goal

  Clean, modular project with 3 phases: **Extract** (SPARQL → JSON) → **Load** (JSON → SQLite) → **Enrich** (SQLite → SQLite). No Pydantic, no checkpoints, no Wikipedia (for
  now).

## Phase 1: Extraction Scripts (SPARQL → JSON)

  All extraction scripts save results as JSON to `data/extracted/`. Each script is standalone and can be re-run independently. They use multiprocessing for parallelism and tqdm
  for progress.

### `extraction/wikidata_api.py` — Shared SPARQL wrapper

  Cleaned-up version of existing `wikidata_extract.py`:

  ```python
  def sparql_query(query: str) -> list[dict]:                                                                                                                                         
  """Execute SPARQL query against Wikidata, return list of dicts."""                                                                                                                  
  ```

### Individuals Extraction

  | Script | What it extracts | SPARQL Properties | Output file |
  |--------|-----------------|-------------------|-------------|
  | `01_extract_occupations.py` | All sub-occupations of writer/artist/scientist | P279* on Q36180, Q901, Q483501 | `occupations.json` |
  | `02_extract_individuals.py` | All individuals with those occupations | P106 | `individuals.json` |
  | `03_extract_individual_info.py` | Gender, birthdate, nationality, birthcity, deathcity | P21, P569, P27, P19, P20, P570 | `individual_info.json` |
  | `04_extract_sitelinks.py` | Wikipedia page URLs per individual | schema:about | `sitelinks.json` |
  | `05_extract_birthcity_details.py` | Country + coordinates for each birthcity | P17, P625 | `birthcity_details.json` |
  | `06_extract_deathcity_details.py` | Country + coordinates for each deathcity | P17, P625 | `deathcity_details.json` |
  | `07_extract_nationality_coords.py` | Coordinates for nationality entities | P625 | `nationality_coords.json` |
  | `08_extract_identifiers.py` | External identifier properties per individual | wikibase:ExternalId | `individual_identifiers.json` |
  | `09_extract_deathyear.py` | Death year per individual | P570 + YEAR() | `deathyears.json` |

### Works Extraction

  | Script | What it extracts | SPARQL Properties | Output file |
  |--------|-----------------|-------------------|-------------|
  | `01_extract_notable_works.py` | Notable works per individual | P800, P31, P571 | `notable_works.json` |
  | `02_extract_authored_works.py` | Works where individual is author/creator | P50, P170, P31, P571, P577 | `authored_works.json` |
  | `03_extract_work_instances.py` | Instance type for each work | P31 | `work_instances.json` |
  | `04_extract_work_identifiers.py` | External IDs for each work | wikibase:ExternalId | `work_identifiers.json` |

  **Key improvement vs current code**: No "badly extracted" variants. Each script handles ALL individuals/works in one unified pass with proper chunking and error handling.

## Phase 2: Loading Scripts (JSON → SQLite)

  Each script reads from `data/extracted/` JSON files and inserts into the SQLite database. Scripts create their tables on first run (CREATE TABLE IF NOT EXISTS) so they're
  idempotent.

### `loading/utils.py` — Shared helpers

  ```python
  def get_db_connection() -> sqlite3.Connection                                                                                                                                       
  def split_wiki(url: str) -> str          # Extract Q-ID from Wikidata URL                                                                                                           
  def clean_date(raw_date: str) -> int     # Parse date string to year                                                                                                                
  def point_to_coordinate(wkt: str) -> tuple  # Parse "Point(lon lat)"                                                                                                                
  ```

  ---

## Phase 3: Enrichment Scripts (SQLite → SQLite)

  Each script reads from the database, computes something, and writes back. Can be re-run independently.

  | Script | Reads | Computes | Updates |
  |--------|-------|----------|---------|
  | `01_enrich_country.py` | birthcity/deathcity/nationality coords | Point-in-polygon via geopandas | `individuals.country_code/country_name/country_data_origin` |
  | `02_enrich_impact_years.py` | `individuals.birthyear` | `(birthyear+35-25)` to `(birthyear+35+25)` | `individuals.impact_year_start/end` |
  | `03_enrich_regions.py` | individuals + region CSV | Country+year+coordinate matching | `individual_regions` |
  | `04_enrich_regions_manual.py` | individual_regions + Excel | Manual corrections | `individual_regions` |
  | `05_clean_individuals.py` | All tables | Filter: has birthyear, region, identifiers, valid name | `individuals_kept` |

## Database Schema

  ```sql
  CREATE TABLE individuals (                                                                                                                                                          
  wikidata_id         TEXT PRIMARY KEY,                                                                                                                                               
  name                TEXT,                                                                                                                                                           
  birthyear           INTEGER,                                                                                                                                                        
  country_code        TEXT,                                                                                                                                                           
  country_name        TEXT,                                                                                                                                                           
  country_data_origin TEXT,                                                                                                                                                           
  impact_year_start   INTEGER,                                                                                                                                                        
  impact_year_end     INTEGER,                                                                                                                                                        
  identifier_count    INTEGER DEFAULT 0                                                                                                                                               
  );                                                                                                                                                                                  
                                                                                                                                                                                      
  CREATE TABLE individual_gender (wikidata_id TEXT, gender TEXT);                                                                                                                     
  CREATE TABLE occupations (occupation_wikidata_id TEXT PRIMARY KEY, occupation_name TEXT, occupation_category TEXT);                                                                 
  CREATE TABLE individual_occupations (wikidata_id TEXT, occupation_wikidata_id TEXT);                                                                                                
                                                                                                                                                                                      
  CREATE TABLE individual_nationality (wikidata_id TEXT, nationality_wikidata_id TEXT, nationality_name TEXT, longitude REAL, latitude REAL);                                         
  CREATE TABLE individual_birthcity (wikidata_id TEXT, birthcity_wikidata_id TEXT, birthcity_name TEXT);                                                                              
  CREATE TABLE birthcity (birthcity_wikidata_id TEXT PRIMARY KEY, birthcity_name TEXT, country_wikidata_id TEXT, country_name TEXT, longitude REAL, latitude REAL);                   
  CREATE TABLE individual_deathcity (wikidata_id TEXT, deathcity_wikidata_id TEXT, deathcity_name TEXT);                                                                              
  CREATE TABLE deathcity (deathcity_wikidata_id TEXT PRIMARY KEY, deathcity_name TEXT, country_wikidata_id TEXT, country_name TEXT, longitude REAL, latitude REAL);                   
  CREATE TABLE deathyear (wikidata_id TEXT, deathyear INTEGER);                                                                                                                       
                                                                                                                                                                                      
  CREATE TABLE individual_sitelinks (wikidata_id TEXT, url TEXT, language TEXT);                                                                                                      
                                                                                                                                                                                      
  CREATE TABLE regions (region_code TEXT PRIMARY KEY, region_name TEXT);                                                                                                              
  CREATE TABLE individual_regions (wikidata_id TEXT, region_code TEXT);                                                                                                               
                                                                                                                                                                                      
  CREATE TABLE identifiers (identifier_wikidata_id TEXT PRIMARY KEY, identifier_name TEXT, country_wikidata_id TEXT, country_name TEXT, identifier_url TEXT);                         
  CREATE TABLE individual_identifiers (wikidata_id TEXT, identifier_wikidata_id TEXT);                                                                                                
  CREATE TABLE individual_viaf (wikidata_id TEXT, viaf_id TEXT);                                                                                                                      
                                                                                                                                                                                      
  CREATE TABLE works (work_wikidata_id TEXT PRIMARY KEY, work_name TEXT, instance_wikidata_id TEXT, instance_label TEXT, super_instance_wikidata_id TEXT, super_instance_label        
  TEXT, work_category TEXT, creation_year INTEGER);                                                                                                                                   
  CREATE TABLE individual_works (wikidata_id TEXT, work_wikidata_id TEXT, relationship TEXT DEFAULT 'creator');                                                                       
  CREATE TABLE work_identifiers (work_wikidata_id TEXT, identifier_wikidata_id TEXT, identifier_name TEXT);                                                                           
                                                                                                                                                                                      
  CREATE TABLE country_continent (country_wikidata_id TEXT, country_name TEXT, continent_wikidata_id TEXT, continent_name TEXT);                                                      
  CREATE TABLE individuals_kept (wikidata_id TEXT PRIMARY KEY);                                                                                                                       
  ```
